# PDF Grouping 0.1.53

## English

### Changed
- The language-switch and "i" (About) buttons moved from the top-right corner of the window down
  into the "File path" panel, right below the file path and the "Total pages in source" count.
- The file-path field, the page-count line, and the (now relocated) language/about buttons share
  one pale background panel, visually grouping these three related pieces of information about
  the active source.
- Faint arrow markers now appear between "Page ranges", "File name", and "Output files", showing
  the left-to-right order in which these panels are normally used (pick a range → name the file →
  get the output files).
- The gap from the window's right edge to the nearest element now exactly matches the gap on the
  left (both 12px) — previously the right side reserved extra space for the scrollbar, making it
  noticeably wider than the left.

## Русский

### Изменено
- Кнопки смены языка и «i» (О программе) перенесены из правого верхнего угла окна в панель «Путь
  к файлу» — сразу под путём к файлу и строкой «Всего страниц в источнике».
- Поле пути к файлу, строка с количеством страниц и (теперь перенесённые) кнопки языка/о программе
  объединены одной бледной подложкой — визуально это одна группа сведений об активном источнике.
- Между секторами «Диапазоны страниц», «Имя файла» и «Файлы для вывода» появились бледные стрелки —
  показывают порядок работы слева направо (задать диапазон → назвать файл → получить файлы).
- Поле от правого края окна до ближайшего элемента теперь точно равно полю слева (по 12px с каждой
  стороны) — раньше справа резервировалось место под полосу прокрутки, из-за чего оно было заметно
  шире левого.
