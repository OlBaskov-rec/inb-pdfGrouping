# PDF Grouping 0.1.52

## English

### Changed
- Source-number badges (the small "N" tag next to a source file and next to a range) are now
  brown instead of blue.
- "Files to process" panel renamed to "Sources to process".
- In "Page ranges", a range's source-file tag is now brown too (matching the file list) and now
  reads "[Source N]" instead of a bare "[N]".
- The same "[Source N]" wording is now used consistently everywhere a source tag appears: the
  ranges list, the range summaries inside "Output files", and the conflict-resolution proposal
  list.
- The language-switch and "i" (About) buttons in the top bar are shifted left, so the window's
  right margin now matches the left margin (previously the top bar sat closer to the edge than
  the panels below it).

## Русский

### Изменено
- Метки-номера источника (маленькая цифра рядом с файлом-источником и рядом с диапазоном)
  теперь коричневые вместо синих.
- Панель «Файлы для обработки» переименована в «Источники для обработки».
- В «Диапазонах страниц» метка исходного файла у диапазона тоже стала коричневой (как в общем
  списке файлов) и теперь пишется как «[N источник]» вместо голого «[N]».
- Та же формулировка «[N источник]» теперь используется везде, где встречается метка источника:
  в списке диапазонов, в сводках диапазонов внутри «Файлы для вывода» и в списке предложений при
  разрешении конфликтов.
- Кнопки смены языка и «i» (О программе) в верхней панели сдвинуты левее — правое поле окна
  теперь равно левому (раньше верхняя панель была ближе к краю, чем панели ниже).
