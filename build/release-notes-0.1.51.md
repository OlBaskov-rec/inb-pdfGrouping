# PDF Grouping 0.1.51

## English

### Changed
- "Group label" panel renamed to "File name" — since a group is really the future output file.
- "Created groups" panel renamed to "Output files".
- The gap before the create buttons in "File name" and before "Clear"/"Preview" in "Page ranges"
  is now larger and equal in both places (was inconsistent — small in one, larger in the other).
- The "[N]" file-number tag on a range now matches the size of the page numbers next to it
  (previously smaller), so it reads clearly at a glance.
- The range list inside "Output files" now uses the same wording as "Page ranges" ("p. X–Y (N p.)"
  for each range) instead of a bare "X–Y" list — first version for review; may be simplified
  further, or dropped, based on feedback.

## Русский

### Изменено
- Панель «Метка группы» переименована в «Имя файла» — ведь группа это, по сути, будущий
  выходной файл.
- Панель «Сформированные группы» переименована в «Файлы для вывода».
- Отступ перед кнопками создания в «Имени файла» и перед «Очистить»/«Предпросмотр» в «Диапазонах
  страниц» теперь больше и одинаковый в обоих местах (раньше был разным — маленьким в одном,
  побольше в другом).
- Метка «[N]» (номер файла) у диапазона теперь того же размера, что и номера страниц рядом
  (раньше была мельче) — так лучше читается.
- Список диапазонов внутри «Файлы для вывода» теперь оформлен теми же словами, что и «Диапазоны
  страниц» («Стр. X–Y (N стр.)» на каждый диапазон), вместо голого перечня «X–Y» — первый вариант
  на просмотр; может быть упрощён ещё сильнее или убран вовсе по итогам обратной связи.
