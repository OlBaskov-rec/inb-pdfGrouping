# PDF Grouping 0.1.50

## English

### Fixed
- In the "Page ranges" list, a long source file name no longer overlaps the ✕ remove button.

### Changed
- Ranges are now tagged with a short, non-editable file number, e.g. "[1] p. 45–290", instead of
  the full (potentially long) file name — this was the direct cause of the overlap above.
- The file list on the left now shows that same number in its own "No." column next to each file,
  so it's easy to see which number corresponds to which file.
- A thin separator line was added between rows in the file list.
- In the "Group label" panel, the two create buttons now sit right below the A–E quick-pick
  buttons with the same standard spacing used elsewhere, instead of being pushed down with a
  large empty gap.

## Русский

### Исправлено
- В списке «Диапазоны страниц» длинное имя исходного файла больше не наезжает на кнопку ✕.

### Изменено
- Диапазоны теперь помечаются коротким нередактируемым номером файла, например «[1] Стр.
  45–290», вместо полного (потенциально длинного) имени файла — это и было прямой причиной
  наезда выше.
- Список файлов слева теперь показывает тот же номер в отдельной колонке «№» рядом с каждым
  файлом — легко понять, какому файлу какой номер соответствует.
- Между строками в списке файлов добавлена тонкая линия-разделитель.
- В панели «Метка группы» обе кнопки создания теперь идут сразу под кнопками быстрого выбора
  A–E со стандартным интервалом, как и везде, а не прижаты к низу с большим пустым разрывом.
