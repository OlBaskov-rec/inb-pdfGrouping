# PDF Grouping 0.1.55

## English

### Added
- Preview of source files: select any file in "Sources to process" (with Preview on) and its pages
  are shown, starting from page 1 — two consecutive pages with a page selector. Returning to a file
  restores the pages you were last viewing in it.
- Moving preview focus: the file you are previewing is highlighted in blue with a magnifier icon
  (before the ✕); selecting a range in "Page ranges" moves the focus there — the blue highlight
  leaves the file and stays on the range, and vice versa.

## Русский

### Добавлено
- Предпросмотр исходных файлов: выберите любой файл в «Источниках для обработки» (при включённом
  предпросмотре) — показываются его страницы с первой, две подряд, с выбором страницы. При возврате
  на файл показываются последние просматриваемые в нём страницы.
- Переходящий фокус предпросмотра: просматриваемый файл подсвечен синим со значком лупы (перед
  ✕); при выборе диапазона в «Диапазонах страниц» фокус переходит туда — синяя подсветка уходит с
  файла и остаётся на диапазоне, и наоборот.
