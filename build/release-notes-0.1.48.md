# PDF Grouping 0.1.48

## English

### Changed
- The "Current ranges" list in the "Group label" panel was removed: it only duplicated the same
  ranges already shown in full (with remove buttons) in the "Page ranges" list on the left, adding
  no extra function and only risking confusion about which list was authoritative.
- The two create buttons are renamed to talk about the output file rather than the internal
  "group" concept: "Create output file ►" and "Create output files for each range ►".

## Русский

### Изменено
- Список «Текущие диапазоны» в панели «Метка группы» убран: он лишь дублировал те же диапазоны,
  уже полностью показанные (с кнопками удаления) в списке «Диапазоны страниц» слева, не добавляя
  функциональности и рискуя запутать — какой список считать «настоящим».
- Обе кнопки создания переименованы с акцентом на выходной файл, а не на внутреннее понятие
  «группа»: «Создать файл для вывода ►» и «Создать файлы для вывода каждого диапазона ►».
